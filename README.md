# Finance Manager Calculator

เว็บแอปเครื่องคิดเลขทางการเงินภาษาไทยสำหรับ Finance Manager รองรับ NPV, IRR, Break-even Point, Loan Calculation และ Financial Ratio

เปิด `dist/index.html` เพื่อใช้งานในเบราว์เซอร์

## Firebase Authentication

แอปเชื่อมต่อกับ Firebase project `data-base-calculator` และรองรับ Email/Password Authentication ได้แก่ สมัครสมาชิก เข้าสู่ระบบ รีเซ็ตรหัสผ่าน และออกจากระบบ

ก่อนใช้งานจริง ต้องเปิด Provider ที่ Firebase Console: **Authentication → Sign-in method → Email/Password → Enable**
